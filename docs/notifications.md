# Уведомления

Два канала, оба работают с теми же данными, что и сайт.

| Канал | Кому | Что нужно |
|---|---|---|
| Web Push | приложение (TWA) и сайт в Chrome | service worker, VAPID-ключи, подписки на VPS |
| Telegram | личный чат | готовый `bot.py` и токен |

Начинать проще с Telegram: инфраструктура уже есть. Web Push добавляется, когда
приложением начнут пользоваться всерьёз.

## Что имеет смысл присылать

**Цены**

- BTC за час -5%: «BTC -5,2% за час, $76 121».
- USD выше 83 ₽: порог задаёт пользователь.
- Акция выросла на 10% за день.
- Золото обновило максимум за месяц.

**Вклады**

- Появился вклад выше 17%: «Альфа-Банк · 17,2% · 12 мес. · от 100 000 ₽».
- Ставка отслеживаемого банка изменилась.
- Еженедельно: топ-3 вклада по ставке.

**Недвижимость**

- Новое объявление по сохранённому фильтру: город, комнаты, бюджет.
- Цена квартиры из избранного снизилась: «-300 000 ₽, 8 900 000 ₽».
- Средняя цена м² в городе изменилась больше чем на 2% за неделю.

**Сводки**

- Утро, 10:00: курсы, ключевая ставка, топ-вклад, одна интересная квартира.
- Вечер, 19:00: что изменилось за день по позициям из избранного.

**Служебные**

- Источник не отвечает дольше 6 часов: «MOEX недоступен, акции из кэша».
- Данные устарели: «Недвижимость не обновлялась 14 часов».

## Web Push

1. Сгенерировать ключи (один раз):

```bash
python -c "import base64,os;print(base64.urlsafe_b64encode(os.urandom(65)).rstrip(b'=').decode())"
```

Публичный ключ уходит на сайт, приватный хранится на VPS в переменной окружения.

2. `web/sw.js` — обработчик `push` и `notificationclick`:

```js
self.addEventListener('push', (event) => {
  const data = event.data ? event.data.json() : {};
  event.waitUntil(self.registration.showNotification(data.title || 'Монетка', {
    body: data.body || '',
    icon: '/icons/icon-192.png',
    badge: '/icons/icon-96.png',
    data: { url: data.url || '/' },
    tag: data.tag,
  }));
});

self.addEventListener('notificationclick', (event) => {
  event.notification.close();
  event.waitUntil(clients.openWindow(event.notification.data.url));
});
```

3. Подписка: кнопка на сайте вызывает `registration.pushManager.subscribe(...)`
   и отправляет объект на `POST /api/push/subscribe` (на VPS, с токеном).

4. Отправка на VPS: `pywebpush` раз в 5 минут проходит по подпискам, считает
   пороги и шлёт то, что сработало. Просроченные подписки (`410`, `404`) удаляются.

5. Порог срабатывания хранить рядом с подпиской, чтобы не спамить: например,
   не чаще одного сообщения на актив в 6 часов.

## Telegram

Дешевле и быстрее: у бота уже есть кнопки и доступ к тем же `/api/bot`.
Добавляется команда `/watch btc -5` и таблица `user_id → актив → условие`,
проверка тем же пятиминутным циклом, что греет кэш на VPS.

Ограничение: Telegram не умеет будить приложение, только присылать сообщение
в чат. Для «пушей как в приложении» нужен Web Push.
