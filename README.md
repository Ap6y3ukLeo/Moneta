# Монетка

Сервис аналитики: криптовалюта, драгметаллы, вклады банков, недвижимость, курсы валют и личный портфель с полным расчётом. Дизайн — по референсам «Монетка».

## Запуск

```powershell
cd monetka
python server.py
```

Откроется `http://127.0.0.1:8787`. Нужен Python 3.10+, зависимостей нет.
Для объявлений Авито, Циана и БН.ру нужен установленный Google Chrome — сервер сам запускает его в headless-режиме и обходит JS-проверку. Путь можно задать переменной `CHROME_PATH`.

## Что внутри

| Раздел | Источник | Как обновляется |
|---|---|---|
| Криптовалюта (12 монет) | Bybit v5 spot API, резерв — CoinPaprika | каждые 2 минуты, при ошибке — последний кэш |
| Драгметаллы (Au, Ag, Pt, Pd) | ЦБ РФ, `xml_metall.asp` | раз в 30 минут |
| Курсы валют | ЦБ РФ (`cbr-xml-daily.ru`, резерв — cbr.ru) | раз в 30 минут |
| Вклады (~300 предложений) | Банки.ру, Банкирос, Финуслуги, Сравни.ру | раз в 3 часа, у каждого источника свой кэш |
| Недвижимость | Авито (вся Россия), Циан и БН.ру (Санкт-Петербург), «Мир квартир» (средние цены Москвы) | раз в 3 и 6 часов |
| Ключевая ставка | ЦБ РФ | раз в 6 часов |

Логотипы банков подтягиваются с CDN витрин; если логотип не загрузился, показывается первая буква банка. Сервер кэширует ответы в `data/*.json` и отдаёт последние успешные данные, если источник недоступен.

## Криптовалюта и Bybit

Цены, изменение за 24 часа и семидневные графики берутся с Bybit. У каждой монеты есть ссылка на спотовую пару вида `https://www.bybit.com/trade/spot/BTC/USDT` — она открывается из таблицы, поиска, карточки на главной и окна добавления в портфель. Рублёвая цена считается по курсу ЦБ РФ.

## Профили

В верхней панели можно создать до 10 локальных профилей, переименовать или удалить их. У каждого профиля отдельный портфель; данные хранятся только в `localStorage` браузера и никуда не отправляются. Старый портфель автоматически переносится в профиль «Алексей».

## Портфель

- Крипта и металлы: количество × текущая цена, пересчёт USD→RUB по курсу ЦБ.
- Вклады: начисление с капитализацией (месяц/квартал) или простой процент, НДФЛ 13% с процентов сверх 1 млн × ключевая ставка.
- Итоги: стоимость, вложено, прибыль, доля каждого актива, изменение за сутки, доходность XIRR по денежным потокам.
- Данные лежат в `localStorage` браузера, никуда не отправляются. Есть демо-портфель.

## Vercel

Репозиторий готов к импорту в Vercel: статика отдаётся из `web/`, `/api/*` — из `api/index.py`. Для Vercel нужен план с лимитом функции не меньше 60 секунд; кэш пишется в `/tmp`, а `data/*.json` из репозитория используется как резервный снимок.

Ограничение: headless Chrome на Vercel недоступен, поэтому Авито, Циан и БН.ру там показываются из последних снимков `data/realty_avito.json`, `data/realty_cian.json` и `data/realty_bn.json`. Для живого парсинга этих площадок запускайте сервер локально.

## Ограничения

- Витрины вкладов отдают максимальные ставки; итоговые условия и доступность зависят от банка, суммы, срока и клиента. Промоставки могут действовать только для новых клиентов или ограниченной суммы.
- Один и тот же вклад может встречаться на разных витринах с разными условиями — он помечен источником, чтобы можно было сравнить.
- Недвижимость — выборка последних объявлений: Авито по всей России, Циан и БН.ру по Санкт-Петербургу. Сервис собирает несколько страниц выдачи (Циан и БН.ру — до 20), поэтому в выдаче около тысячи объявлений; Авито может ограничивать глубину после 1–2 страниц из-за антибота. Городской фильтр и поиск работают по всей выборке; медиана и средняя цена м² считаются по национальной выборке Авито, а не по всему рынку. Средние цены Москвы — оценка «Мир квартир».
- Авито и Циан могут менять разметку или временно включать антибот; в этом случае сервис отдаёт предыдущий кэш.
- Налог по вкладам считается по текущей ключевой ставке, а не по максимальной за год.
- Данные публичные и актуальны на момент запроса; сервис не является инвестиционной или оценочной рекомендацией.
