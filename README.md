# Монетка

Сервис аналитики: криптовалюта, драгметаллы, вклады банков, недвижимость, курсы валют и личный портфель с полным расчётом. Дизайн — по референсам «Монетка».

## Запуск

```powershell
cd monetka
python server.py
```

Откроется `http://127.0.0.1:8787`. Нужен Python 3.10+, зависимостей нет.
Для Авито и Циана нужен установленный Google Chrome — сервер сам запускает его в headless-режиме. Путь можно задать переменной `CHROME_PATH`. Яндекс.Недвижимость и БН.ру отдают данные обычному HTTP-клиенту.

## Что внутри

| Раздел | Источник | Как обновляется |
|---|---|---|
| Криптовалюта (12 монет) | Bybit v5 spot API, резерв — CoinPaprika | раз в час; кнопка «Обновить» — принудительно |
| Драгметаллы (Au, Ag, Pt, Pd) | ЦБ РФ, `xml_metall.asp` | раз в час; кнопка «Обновить» — принудительно |
| Курсы валют | ЦБ РФ (`cbr-xml-daily.ru`, резерв — cbr.ru), биржа — MOEX, для EUR и остальных пар без торгов — Coinbase | ЦБ — раз в час, биржа — каждые 15 минут; кнопка «Обновить» — принудительно |
| Вклады | Сайты банков: ВТБ, Газпромбанк, Россельхозбанк, Т-Банк, Банк ДОМ.РФ, Альфа-Банк, ОТП Банк | раз в 3 часа, только продукты с онлайн-оформлением |
| Недвижимость | Яндекс.Недвижимость (вся Россия и 35 крупных городов), Авито (вся Россия), Циан и БН.ру (Санкт-Петербург), «Мир квартир» (средние цены Москвы) | раз в 3 и 6 часов |
| Ключевая ставка | ЦБ РФ | раз в 6 часов |

Логотипы банков лежат в `web/logos/` и отдаются локально; если логотип не загрузился, показывается первая буква банка. Сервер кэширует ответы в `data/*.json` и отдаёт последние успешные данные, если источник недоступен.

Официальный курс ЦБ РФ публикуется раз в рабочий день. Для внутридневной динамики рядом показывается биржевой курс: MOEX для пар, которые там торгуются, и Coinbase для EUR, GBP, CHF, JPY — MOEX не торгует EUR с 2024 года, а Yahoo из России недоступен. В расчётах портфеля используется официальный курс ЦБ, чтобы не смешивать источники.

## Недвижимость

Карточка объявления открывается внутри сервиса по клику на фото или кнопке «Подробнее»: галерея фото, цена, цена за м², город, район, метро, площадь и тип. Для объявлений Яндекса сервер подтягивает несколько фото в высоком разрешении. Ссылка на источник остаётся внутри карточки, но для просмотра информации переходить на сайт не обязательно.

## Криптовалюта и Bybit

Цены, изменение за 24 часа и семидневные графики берутся с Bybit. У каждой монеты есть ссылка на спотовую пару вида `https://www.bybit.com/trade/spot/BTC/USDT` — она открывается из таблицы, поиска, карточки на главной и окна добавления в портфель. Рублёвая цена считается по курсу ЦБ РФ.

## Профили

В верхней панели можно создать до 10 локальных профилей, переименовать или удалить их. У каждого профиля отдельный портфель; данные хранятся в `localStorage` браузера. Старый портфель автоматически переносится в профиль «Алексей».

## Портфель

- Крипта, металлы и валюта: количество × текущая цена, пересчёт USD→RUB по курсу ЦБ; валюту можно добавить кнопкой «+» на странице курсов.
- Вклады: начисление с капитализацией (месяц/квартал) или простой процент, НДФЛ 13% с процентов сверх 1 млн × ключевая ставка.
- Итоги: стоимость, вложено, прибыль, доля каждого актива, изменение за сутки, доходность XIRR по денежным потокам.
- Данные лежат в `localStorage` браузера. При запросе к AI отправляется только сводка по позициям и рыночным данным, без имени профиля. Есть демо-портфель.

## AI-аналитик

В правом нижнем углу на любой странице есть круглая кнопка — она открывает плавающий чат с нейросетью. Можно задать свой вопрос или выбрать готовый: риски, доходность, вклады, валюта, недвижимость, что умею. Модель получает сводку портфеля, топ вкладов по банкам, криптовалюты, металлы, валюты и статистику недвижимости. Ответы чата поддерживают markdown: списки, **жирный** и `код`.

На страницах «Криптовалюта», «Драгметаллы» и «Валюта» есть интерактивный график: клик по спарклайну или иконке графика открывает окно с историей, зумом колесом, перетаскиванием и диапазонами 1Д/7Д/1М/3М/1Г/Всё. Внутри окна есть переключатель «AI-прогноз» (по умолчанию включён): он показывает или скрывает прогноз и диапазон на графике. Горизонт прогноза подстраивается под диапазон: 1М — 30 дней, 3М/1Г — 90 дней. История длинных диапазонов отдаётся `/api/history` (Bybit с резервом CoinGecko для крипты, ЦБ РФ для металлов и валют); для металлов и валют дневная история, поэтому 1Д скрыт.

Снимки истории лежат в `data/history/` и обновляются командой `python scripts/build_history.py`. На Vercel `/api/history` сразу отдаёт снимки, поэтому графики не зависят от доступности Bybit/ЦБ; локально сначала пробуется live, затем снимок. Это же fallback используется прогнозом.

Числовой прогноз считает статистический ансамбль из трёх моделей (random walk, momentum, mean reversion) с rolling-бэктестом; YandexGPT получает уже посчитанные факты и пишет комментарий, но не генерирует числа. В окне видны точность направления, средняя ошибка бэктеста, волатильность, веса моделей и уровни. Для валют история берётся из динамики ЦБ РФ.

Ограничения: числовая модель использует только историю цены. AI-комментарий получает доступные факторы — ключевую ставку, USD/RUB, объём и breadth крипторынка, отношение золото/серебро, cross-FX. Новости, инфляция, DXY, нефть и ордербук пока не учитываются. Бэктест показывает точность на прошлых точках и не гарантирует будущую. Это вероятностный сценарий для покупки/удержания, не шорт и не рекомендация.

Для локального запуска:

```powershell
$env:YANDEX_GPT_API_KEY="ваш-api-ключ"
$env:YANDEX_GPT_FOLDER_ID="ваш-folder-id"
python server.py
```

Необязательно: `YANDEX_GPT_MODEL` — по умолчанию `yandexgpt/latest`, можно указать `yandexgpt-lite/latest` для дешёвых коротких ответов или полный `gpt://...` URI. Ключ нужен сервисному аккаунту с ролью `ai.languageModels.user` и scope `yc.ai.languageModels.execute`. На Vercel те же переменные добавляются в Settings → Environment Variables. Ключ хранится только на сервере.

Если API отвечает 401, ключ скопирован не полностью, удалён или создан без нужного scope. Создайте новый API-ключ и скопируйте его целиком при создании.

## Файлы

```

web/styles.css  оформление

```

## Vercel

Репозиторий готов к импорту в Vercel: статика отдаётся из `web/`, `/api/*` — из `api/index.py`. `/api/market` всегда собирает свежие котировки, а при ошибке отдаёт снимок из `data/*.json`. Вклады, недвижимость и история отдаются из снимков, чтобы не упираться в лимит функции. Страница сама обновляет рынок раз в час; кнопка «Обновить» запрашивает данные принудительно.

Ограничение: headless Chrome на Vercel недоступен, поэтому Авито, Циан и БН.ру там показываются из последних снимков `data/realty_avito.json`, `data/realty_cian.json` и `data/realty_bn.json`; Яндекс и «Мир квартир» — из `data/realty_yandex.json` и `data/realty_moscow.json`. Для живого парсинга запускайте сервер локально.

## Ограничения

- Вклады берутся только с сайтов самих банков, где продукт можно оформить онлайн; агрегаторы не используются. Ставки максимальные, итоговые условия зависят от суммы, срока и клиента. Промоставки могут действовать только для новых клиентов.
- Недвижимость — выборка последних объявлений: Яндекс.Недвижимость по всей России (25 страниц национальной выдачи и по 10 страниц для 35 крупных городов), Авито по всей России, Циан и БН.ру по Санкт-Петербургу. В выдаче около 8 тысяч объявлений и 280+ городов; у крупных городов — по 100+ квартир. Авито может ограничивать глубину после 1–2 страниц из-за антибота. Городской фильтр и поиск работают по всей выборке; медиана и средняя цена м² считаются по национальной выборке, а не по всему рынку. Средние цены Москвы — оценка «Мир квартир».
- Авито, Циан и Яндекс могут менять разметку или временно включать антибот; в этом случае сервис отдаёт предыдущий кэш.
- Налог по вкладам считается по текущей ключевой ставке, а не по максимальной за год.
- Данные публичные и актуальны на момент запроса; сервис не является инвестиционной или оценочной рекомендацией.
